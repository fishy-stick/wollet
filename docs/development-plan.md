本版本交付两组能力：

- **设备网络状态与时长**：管理页面展示客户端实际连接 IP、本次连接持续时间及 Windows 系统运行时长，正确处理重连、离线和数据过期。

服务端、管理页面和 Windows 客户端以 `v1.2.0` 为目标版本。发布日期根据功能完成和联合验收进度确定，尚未承诺具体日期。

## 设备网络状态与时长

状态：代码及管理页面样式已完成，尚未正式发布。三项功能已按用户确认同时开发；详细设计与验证记录见 [客户端网络状态规划](design/device-network-status.md)。

### 交付范围与数据口径

| 页面字段 | 定义与来源 | 重置或失效条件 |
| --- | --- | --- |
| 连接 IP | 服务端从已认证 WebSocket 的实际对端地址采集，局域网直连时为设备连接所用 IP | 每次新连接重新采集；离线后不显示当前 IP |
| 当前在线 | 当前有效 WebSocket 连接持续时间，由服务端记录连接起点并使用单调时间计算 | 客户端断线重连、服务端或客户端服务重启后重新计时 |
| 系统运行 | Windows 本次内核启动以来的运行时长，由客户端原生计时 API 采集 | 完整系统重启归零；网络重连和客户端服务重启不清零 |

- 页面刷新、重新打开和浏览器 SSE 重连不重置当前在线时长；不得用网页打开时间、设备创建时间或最后心跳时间代替连接起点。
- IP 支持 IPv4／IPv6，只显示服务端实际看到的连接地址，不列举全部网卡，不改变凭据、MAC 或 Wake-on-LAN 目标。NAT／反向代理下显示对端地址，不自动信任转发请求头。
- 旧客户端已有 IP 和当前在线；缺少系统运行时长或采集失败时显示“未知”，不以 0 代替未知。离线后不继续累加；样本过期或 SSE 中断时暂停对应外推并提示待同步，IP 不依赖运行时长样本有效期。
- 首版不保存历史 IP、历史运行时长或累计在线统计，不迁移数据库。
- 系统运行时长已采用原生 `GetTickCount64`，计时口径包含睡眠和休眠时间；快速启动可能延续内核会话。界面使用“系统运行”并解释口径，电源场景的实际行为需在目标 Windows 环境验收。

### 已实现任务

1. 服务端 Hub 增加实际连接对端 IP、连接起点、独立会话 ID 和单调时长，使用当前连接对象身份防止旧连接消息覆盖新会话；扩展 REST／SSE 共用设备视图，让旧客户端也可展示 IP 和当前在线。
2. 客户端使用 Windows 原生系统运行计时，保留原有 WebSocket 传输实现；采集失败不影响心跳与控制连接。
3. 扩展 Go／C# 状态结构及独立能力协商；协商成功后通过首个和周期心跳上报状态，服务端记录样本年龄、有效性及字段校验结果。
4. 管理页面接入 IP 与两种时长，完成未知、离线、过期、断流与恢复处理；每秒仅更新计时文字，避免重建控制按钮或干扰焦点。
5. 已按确认设计整理管理页面文字排布：保留原有基本布局，IP 与 MAC 同行，两种时长收为一行次要信息，文案采用“当前在线”；离线时移除 IP 与分隔线，MAC 单独居中，“最后在线”与在线时长复用同一套文字样式。
6. 时长说明收进信息图标，版本与兼容信息通过“详情”展开；移除正常在线时重复的“连接正常”，功能受限时仍保留提示。
7. 已完成新旧两端自动化联调、网页模拟联调及现行协议说明；真实 Windows 安装和电源／局域网场景验收仍待完成。

### 实现与验证进度

- 已接入独立 `device-status.v1` 系统运行时长能力，保持 `protocolVersion: 1`。默认沿用 15 秒心跳、45 秒样本有效期，并在协商／计划同步完成后立即发送首样本。
- 按用户确认的局域网直连场景，服务端从 WebSocket 请求的 `RemoteAddr` 采集连接 IP，客户端只使用原生 `GetTickCount64` 采集系统运行时长；地址规范化、忽略伪造 IP／转发请求头、旧客户端展示、IPv4／IPv6 连接及采集失败继续控制均有自动化验证。
- 服务端记录单调连接时长与样本年龄，通过 REST／SSE 共用视图提供数据。页面每秒只刷新计时文字，暂停处理覆盖断流、浏览器离线事件、过期、页面后台和恢复，过期 HTTP 响应不能覆盖更新的 SSE 状态。
- Go 测试与 vet、72 项 .NET 客户端测试、9 项网页计时测试及桌面／手机浏览器模拟联调通过，两种 Windows 单文件发行形式已完成 `1.2.0-dev.2` 构建和版本资源检查；真实服务安装、睡眠／休眠／快速启动及实际局域网环境仍需联合验收。Go race detector 因当前环境没有可用 C 编译环境而未运行。
- 最终样式修改后，9 项网页测试及服务端相关测试再次通过；在应用内浏览器确认了时长说明、版本详情、设备切换和离线字段隐藏，并确认在线／离线时间的字号、颜色、行高和间距来自同一套样式，未发现浏览器脚本错误。此前桌面／手机模拟联调记录针对样式修改前的页面；当前样式的专项布局与可读性检查尚未执行。

### 剩余验收事项

- 真实 Windows 服务安装、升级后重连，以及服务重启不重置系统运行时长。
- 完整重启、睡眠、休眠、快速启动与系统校时下的计时行为。
- 实际局域网中的双网卡、IPv4／IPv6、DNS／TLS 连接与 IP 显示。
- 按用户要求，将当前样式的手机、长设备名、多设备、文字放大及可读性专项检查安排在版本最终验收阶段。

### 验收标准

- 页面刷新、多标签页及 SSE 重连后，两种时长语义一致，不错误归零或倒退。
- WebSocket 重连重置当前在线，服务重启不重置系统运行；旧连接迟到的消息不能覆盖新会话。
- 完整重启、睡眠、休眠、快速启动及系统校时符合已确认口径。
- 局域网直连、双网卡、IPv4／IPv6 和 DNS 多地址下，IP 与服务端看到的实际连接对端一致；VPN／NAT／反向代理场景显示对端地址，不承诺还原设备局域网 IP。
- 离线、样本过期、浏览器后台恢复、采集失败及非法可选字段不产生持续增长的过期数据，也不破坏基础控制。
- 新服务端与旧客户端提供 IP 和当前在线，系统运行未知；旧服务端与新客户端不发送未协商状态，基础远程控制继续可用。

## Windows 界面迁移至 WPF

状态：已纳入 v1.2.0，尚未实现。当前 `CountdownForm` 和 `InstallerForm` 均为 WinForms 窗口。

### 交付范围

- 先迁移倒计时窗口，再迁移安装／管理主窗口，统一布局、字体和基础样式。
- 使用 WPF 布局、文字与矢量渲染替代自绘坐标和手动 DPI 缩放，使用属性动画管理圆环进度。高刷新率屏幕上的流畅度需实测，不以框架迁移或定时器间隔作为帧率保证。
- 保留安装、绑定、更新、修复、卸载、兼容提示与后台关机逻辑。动画仅表达计划进度，实际关机仍由后台服务计时执行；状态变化时同步校正或停止动画。
- 保留不抢焦点、默认取消、键盘操作、高对比度、操作期间禁止关闭及异步操作生命周期保护等现有行为；托盘可继续复用现有实现。
- 保留普通用户桌面提示、独立提权的安装管理入口、本地 IPC 和活动控制台会话限制。

### 待开发任务

### 验收标准

## v1.1.0 基线与验收记录

以下记录用于回归与验收追踪，不再作为本版待开发功能。

### 更新保留配对

已实现独立更新入口、版本比较、保留凭据的离线更新，以及先暂存、再停止服务和替换程序的流程。替换或启动失败时尝试恢复旧程序与原服务运行状态；恢复失败保留可用备份并给出修复提示。卸载仍会删除本地凭据，不能通过卸载完成更新。

版本比较支持正式版、预发布版及旧四段数字版本，忽略构建元数据；新版更新、同版修复、旧版和未知版本拦截已接入。网络暂时不可达不会要求重新配对；凭据失效需通过新 Token 绑定。

既有自动化测试覆盖版本排序、无需网络或凭据写入的更新、缺失配置拦截、替换和恢复流程；两种单文件发行形式已完成构建及版本资源检查。真实 Windows 服务从 v1.0.4 升级、DPAPI 凭据复用、恢复连接不产生重复设备，以及失败恢复的安装环境验收记录尚未补齐。配置缺失／损坏、凭据撤销或切换服务端的重新配对边界需补充明确验收记录。

### 同步关机倒计时

协议扩展、客户端计划引擎、命名管道、普通权限桌面提示、安装启动和管理页面均已接入，自动化及模拟联调已有通过记录。客户端自动接受十秒计划，两端可取消或立即执行；关闭页面或临时断网不取消已接受计划，服务重启、更新及睡眠恢复取消未执行计划。桌面提示仅支持活动控制台会话，RDP 暂不支持。

2026-09-28，用户确认 Windows 倒计时已完成人工验收，未弹出提示的问题已关闭。锁屏、多用户切换、睡眠恢复及 100%／200% 缩放等矩阵未逐项记录覆盖结果，既有记录也未确认运行 Go race detector。具体实现和验收记录见 [同步关机开发规划](design/shutdown-countdown-implementation.md) 与 [关机协议设计](design/shutdown-plan-protocol.md)。

### 版本信息与兼容提示

统一功能目录、两端版本上报、页面标签和 Windows 管理窗口提示均已实现。基础远程开关机、更新保留配对及倒计时已登记 v1.1.0 正式版本映射，不再标为待实现。

既有自动化测试和界面检查已有通过记录，本次新增状态功能后全套自动化回归通过；真实安装后的 IPC 与跨版本联合验收记录尚未补齐。详细规则见 [版本信息与兼容提示](design/version-compatibility-hints.md)。
