# v1.2.0 功能范围与后续方向

本文保留版本功能范围、设计约束和后续需求。开发进度以 Pull Request 为准，已发布版本、附件和发布时间以 [GitHub Releases](https://github.com/fishy-stick/wollet/releases) 为准；不在本文维护测试 tag 或发布排期。

现行通信契约见 [通信协议](protocol.md)，具体验证结果与覆盖边界见各功能的设计记录。

## v1.2.0 功能范围

本版本交付两组能力：

- **设备网络状态与时长**：管理页面展示客户端实际连接 IP、本次连接持续时间及 Windows 系统运行时长，正确处理重连、离线和数据过期。
- **Windows 界面迁移至 WPF**：迁移倒计时窗口与安装／管理窗口，改善动画、文字渲染、高 DPI 和跨屏缩放效果，保留现有功能与交互约束。

## 设备网络状态与时长

三项状态功能同时提供；详细设计与验证记录见 [设备网络状态设计](design/device-network-status.md)。

### 交付范围与数据口径

| 页面字段 | 定义与来源 | 重置或失效条件 |
| --- | --- | --- |
| 连接 IP | 服务端从已认证 WebSocket 的实际对端地址采集，局域网直连时为设备连接所用 IP | 每次新连接重新采集；离线后不显示当前 IP |
| 当前在线 | 当前有效 WebSocket 连接持续时间，由服务端记录连接起点并使用单调时间计算 | 客户端断线重连、服务端或客户端服务重启后重新计时 |
| 系统运行 | Windows 本次内核启动以来的运行时长，由客户端原生计时 API 采集 | 完整系统重启归零；网络重连和客户端服务重启不清零 |

- 页面刷新、重新打开和浏览器 SSE 重连不重置当前在线时长；不得用网页打开时间、设备创建时间或最后心跳时间代替连接起点。
- IP 支持 IPv4／IPv6，只显示服务端实际看到的连接地址，不列举全部网卡，不改变凭据、MAC 或 Wake-on-LAN 目标。NAT／反向代理下显示对端地址，不自动信任转发请求头。
- 旧客户端已有 IP 和当前在线；缺少系统运行时长或采集失败时显示“未知”，不以 0 代替未知。离线后不继续累加；样本过期或 SSE 中断时暂停对应外推并提示待同步，IP 不依赖运行时长样本有效期。
- 首版不保存历史 IP、历史运行时长或累计在线统计，不迁移数据库。
- 系统运行时长已采用原生 `GetTickCount64`，计时口径包含睡眠和休眠时间；快速启动可能延续内核会话。界面使用“系统运行”并解释口径。

### 验收标准

- 页面刷新、多标签页及 SSE 重连后，两种时长语义一致，不错误归零或倒退。
- WebSocket 重连重置当前在线，服务重启不重置系统运行；旧连接迟到的消息不能覆盖新会话。
- 完整重启、睡眠、休眠、快速启动及系统校时符合已确认口径。
- 局域网直连、双网卡、IPv4／IPv6 和 DNS 多地址下，IP 与服务端看到的实际连接对端一致；VPN／NAT／反向代理场景显示对端地址，不承诺还原设备局域网 IP。
- 离线、样本过期、浏览器后台恢复、采集失败及非法可选字段不产生持续增长的过期数据，也不破坏基础控制。
- 新服务端与旧客户端提供 IP 和当前在线，系统运行未知；旧服务端与新客户端不发送未协商状态，基础远程控制继续可用。

## Windows 界面迁移至 WPF

客户端使用 WPF，移除 WinForms 依赖和旧窗口，抽离独立应用层。详细架构、验证结果与覆盖边界见 [WPF 迁移记录](design/wpf-migration.md)。Windows 10／11 均为支持目标。

### 交付范围

- 倒计时窗口和安装／管理主窗口统一使用 WPF 布局、字体和基础样式。
- 使用 WPF 布局、文字与矢量渲染替代自绘坐标和手动 DPI 缩放，使用属性动画管理圆环进度。高刷新率屏幕上的流畅度需实测，不以框架迁移或定时器间隔作为帧率保证。
- 保留安装、绑定、更新、修复、卸载、兼容提示与后台关机逻辑。动画仅表达计划进度，实际关机仍由后台服务计时执行；状态变化时同步校正或停止动画。
- 保留不抢焦点、默认取消、键盘操作、高对比度、操作期间禁止关闭及异步操作生命周期保护等现有行为；连续 IPC 失败时的临时托盘警告已改用原生 Windows API，没有常驻托盘菜单。
- 保留普通用户桌面提示、独立提权的安装管理入口、本地 IPC 和活动控制台会话限制。

### 验收标准

- 覆盖 100%、150%、200% 缩放、不同 DPI 显示器之间移动、普通与高刷新率屏幕、长状态文本和错误提示。
- 倒计时显示与后台计划一致，取消、立即执行、失败和断线恢复不残留过期窗口，不改变关机执行次数。
- 首次安装、绑定、更新保留配对、同版修复、降级拦截、未知版本处理及卸载保持现有行为。
- 已有资源测量仅保留为迁移记录；以一次性使用场景为准，不安排专项性能测试或性能发布门槛。

## 既有功能与兼容约束

更新保留配对、同步关机倒计时和版本兼容提示属于既有功能，已完成人工验收。行为说明分别见 [README](../README.md)、[关机协议设计](design/shutdown-plan-protocol.md) 和 [版本信息与兼容提示](design/version-compatibility-hints.md)。

新功能保持以下约束：

- 包含 .NET Runtime 和 framework-dependent 两种客户端发行形式使用相同功能与更新流程。
- 新服务端与旧客户端、旧服务端与新客户端保持基础控制可用；完整新增状态需要两端支持。
- 更新保留现有配对；客户端更新不依赖服务端先行升级。
- 功能目录只维护正式版本的精确映射，不逐个登记预发布 tag。
- 通用构建、测试、发布与部署步骤统一见 [README](../README.md#从源码开发)。

## 后续需求

### 远程休眠选项

未纳入 v1.2.0 功能范围。

为远程关机增加可选的休眠方式。后续需确定保持简洁的操作入口、默认行为、是否沿用倒计时／取消／立即执行，以及客户端能力检测、不支持时的提示和协议扩展。

自动检查版本、自动下载和静默安装，以及动态调整关机倒计时时长，同样未纳入本版交付范围。
