## v1.2.0 版本目标

本版本交付两组能力：

- **设备网络状态与时长**：管理页面展示客户端实际连接 IP、本次连接持续时间及 Windows 系统运行时长，正确处理重连、离线和数据过期。
- **Windows 界面迁移至 WPF**：迁移倒计时窗口与安装／管理窗口，改善动画、文字渲染、高 DPI 和跨屏缩放效果，保留现有功能与交互约束。

服务端、管理页面和 Windows 客户端以 `v1.2.0` 为目标版本。发布日期根据功能完成和联合验收进度确定，尚未承诺具体日期。

## 设备网络状态与时长

状态：设计草案，尚未实现。已确认同时展示连接网卡 IP、本次连接时长和系统运行时长。详细方案见 [客户端网络状态规划](design/device-network-status.md)。

### 交付范围与数据口径

| 页面字段 | 定义与来源 | 重置或失效条件 |
| --- | --- | --- |
| 连接 IP | 当前 WebSocket 实际使用的客户端本地 IP，由客户端从连接套接字采集；不是公网出口或代理地址 | 每次新连接重新采集；离线后不显示当前 IP |
| 本次在线 | 当前有效 WebSocket 连接持续时间，由服务端记录连接起点并使用单调时间计算 | 客户端断线重连、服务端或客户端服务重启后重新计时 |
| 系统运行 | Windows 本次内核启动以来的运行时长，由客户端原生计时 API 采集 | 完整系统重启归零；网络重连和客户端服务重启不清零 |

- 页面刷新、重新打开和浏览器 SSE 重连不重置本次在线时长；不得用网页打开时间、设备创建时间或最后心跳时间代替连接起点。
- IP 支持 IPv4／IPv6，只显示实际连接使用的地址，不列举全部网卡，不改变凭据、MAC 或 Wake-on-LAN 目标。
- 采集失败或旧客户端缺少字段时显示“未知”或隐藏，不以 0 代替未知。离线后不继续累加；样本过期或 SSE 中断时暂停外推并提示待同步。
- 首版不保存历史 IP、历史运行时长或累计在线统计，不迁移数据库。
- 系统运行时长拟包含睡眠和休眠时间；快速启动可能延续内核会话。界面使用“系统运行”并解释口径，最终行为需在目标 Windows 环境验收。

### 待开发任务

1. 服务端 Hub 增加连接起点、独立会话 ID 和单调时长，使用当前连接对象身份防止旧连接消息覆盖新会话；扩展 REST／SSE 共用设备视图，让旧客户端也可展示本次在线。
2. 验证实际 WebSocket 本地端点采集和 Windows 原生系统运行计时方案，保留现有直连、TLS 校验、超时、取消及 IPv4／IPv6 回退行为；采集失败不影响心跳与控制连接。
3. 扩展 Go／C# 状态结构及独立能力协商；协商成功后通过首个和周期心跳上报状态，服务端记录样本年龄、有效性及字段校验结果。
4. 管理页面接入 IP 与两种时长，完成未知、离线、过期、断流与恢复处理；每秒仅更新计时文字，避免重建控制按钮或干扰焦点。
5. 联调新旧两端组合，补充自动化测试、现行协议说明和实际 Windows 验收记录。

### 实施前需验证的设计

- 草案建议使用 `device-status.v1` 能力、默认 15 秒心跳采样和 45 秒样本有效期；这些值及字段以协议实现前确认的契约为准，不改变 `protocolVersion: 1`。
- 实际连接本地端点的传输层实现路径需验证，不能用另一次 TCP 路由探测或第一块网卡地址代替。
- 原生系统运行计时在睡眠、休眠、快速启动和完整重启后的行为需验证；客户端不提供壁钟时间，服务端记录样本接收时间与单调年龄。

### 验收标准

- 页面刷新、多标签页及 SSE 重连后，两种时长语义一致，不错误归零或倒退。
- WebSocket 重连重置本次在线，服务重启不重置系统运行；旧连接迟到的消息不能覆盖新会话。
- 完整重启、睡眠、休眠、快速启动及系统校时符合已确认口径。
- 双网卡、VPN、NAT／反向代理、IPv4／IPv6 和 DNS 多地址下，IP 与实际连接端点一致。
- 离线、样本过期、浏览器后台恢复、采集失败及非法可选字段不产生持续增长的过期数据，也不破坏基础控制。
- 新服务端与旧客户端提供本次在线，IP／系统运行未知；旧服务端与新客户端不发送未协商状态，基础远程控制继续可用。

## Windows 界面迁移至 WPF

状态：已纳入 v1.2.0，尚未实现。当前 `CountdownForm` 和 `InstallerForm` 均为 WinForms 窗口。

### 交付范围

- 先迁移倒计时窗口，再迁移安装／管理主窗口，统一布局、字体和基础样式。
- 使用 WPF 布局、文字与矢量渲染替代自绘坐标和手动 DPI 缩放，使用属性动画管理圆环进度。高刷新率屏幕上的流畅度需实测，不以框架迁移或定时器间隔作为帧率保证。
- 保留安装、绑定、更新、修复、卸载、兼容提示与后台关机逻辑。动画仅表达计划进度，实际关机仍由后台服务计时执行；状态变化时同步校正或停止动画。
- 保留不抢焦点、默认取消、键盘操作、高对比度、操作期间禁止关闭及异步操作生命周期保护等现有行为；托盘可继续复用现有实现。
- 保留普通用户桌面提示、独立提权的安装管理入口、本地 IPC 和活动控制台会话限制。

### 待开发任务

1. 梳理 UI 与后台逻辑边界，记录迁移前显示效果、弹窗耗时、资源开销和两种发行形式的包体大小。
2. 迁移倒计时窗口，验证圆环动画、剩余时间校正、取消、立即执行、终态和 IPC 重连。
3. 迁移安装／管理窗口，接入已有安装协调与兼容提示逻辑，验证异步操作、提权和状态刷新。
4. 完成 DPI、跨屏、可访问性、性能及两种单文件发行形式的联合验收。

### 验收标准

- 覆盖 100%、150%、200% 缩放、不同 DPI 显示器之间移动、普通与高刷新率屏幕、长状态文本和错误提示。
- 倒计时显示与后台计划一致，取消、立即执行、失败和断线恢复不残留过期窗口，不改变关机执行次数。
- 首次安装、绑定、更新保留配对、同版修复、降级拦截、未知版本处理及卸载保持现有行为。
- 对比迁移前后的首次弹窗耗时、内存、动画 CPU／GPU 开销和包体大小，记录显示改善及资源成本；量化通过门槛在迁移基线测量后确定。

## 建议实施顺序

以下为本次整理提出的建议，尚未作为用户确认的开发优先级；两组功能都属于已确认的版本范围。

1. **先实现本次连接时长**：完成 Hub 元数据、REST／SSE 和页面展示，交付一个不依赖 Windows 客户端更新、旧客户端也能使用的完整功能。
2. **补齐连接 IP 与系统运行时长**：先验证采集方案，再接入能力协商、心跳上报和页面状态，完成设备网络状态这一组功能。
3. **迁移 WPF 倒计时窗口**：保持计划引擎与协议稳定，集中验证动画、渲染和桌面行为。
4. **迁移 WPF 安装／管理窗口**：复用既有安装与兼容逻辑，完成界面迁移。
5. **完成联合验收与发布准备**：补齐基线验收记录，更新协议、README 和发布说明。

## 联合验收与发布

- 以 v1.1.0 为主要升级与兼容基线；已有记录未覆盖的 v1.0.4 直接升级、DPAPI 复用等场景仍需补充，不因已有 tag 而视为验收完成。
- 包含 .NET Runtime 和 framework-dependent 两种客户端发行形式均覆盖首次安装、升级保留配对、恢复连接、同步倒计时、取消与立即执行，以及本版新增功能。
- 验证新服务端与旧客户端、旧服务端与新客户端、新服务端与新客户端组合，确保新增状态上报不破坏现有控制。客户端更新不依赖服务端先行升级；完整新增状态需要两端支持。
- 开发验证使用递增的 `v1.2.0-dev.N`，需要候选验收时使用 `v1.2.0-rc.N`。发布前检查功能目录，仅对已确认正式版本维护精确映射，不预登记尚未发布版本。
- 两组功能及联合验收完成后，核对远端 tag 和目标提交，再创建并推送 `v1.2.0`；既有发布工作流构建服务端镜像、两个 Windows 客户端并创建 Release。
- 发布说明包含升级方式、建议部署顺序、新字段口径、兼容行为和已知限制。已有发布 tag 保持不变。

## v1.1.0 基线与验收记录

以下记录用于回归与验收追踪，不再作为本版待开发功能。

### 更新保留配对

已实现独立更新入口、版本比较、保留凭据的离线更新，以及先暂存、再停止服务和替换程序的流程。替换或启动失败时尝试恢复旧程序与原服务运行状态；恢复失败保留可用备份并给出修复提示。卸载仍会删除本地凭据，不能通过卸载完成更新。

版本比较支持正式版、预发布版及旧四段数字版本，忽略构建元数据；新版更新、同版修复、旧版和未知版本拦截已接入。网络暂时不可达不会要求重新配对；凭据失效需通过新 Token 绑定。

既有自动化测试覆盖版本排序、无需网络或凭据写入的更新、缺失配置拦截、替换和恢复流程；两种单文件发行形式已完成构建及版本资源检查。真实 Windows 服务从 v1.0.4 升级、DPAPI 凭据复用、恢复连接不产生重复设备，以及失败恢复的安装环境验收记录尚未补齐。配置缺失／损坏、凭据撤销或切换服务端的重新配对边界需补充明确验收记录。

### 同步关机倒计时

协议扩展、客户端计划引擎、命名管道、普通权限桌面提示、安装启动和管理页面均已接入，自动化及模拟联调已有通过记录。客户端自动接受十秒计划，两端可取消或立即执行；关闭页面或临时断网不取消已接受计划，服务重启、更新及睡眠恢复取消未执行计划。桌面提示仅支持活动控制台会话，RDP 暂不支持。

2026-09-28，用户确认 Windows 倒计时已完成人工验收，未弹出提示的问题已关闭。锁屏、多用户切换、睡眠恢复及 100%／200% 缩放等矩阵未逐项记录覆盖结果，既有记录也未确认运行 Go race detector。具体实现和验收记录见 [同步关机开发规划](design/shutdown-countdown-implementation.md) 与 [关机协议设计](design/shutdown-plan-protocol.md)。

### 版本信息与兼容提示

统一功能目录、两端版本上报、页面标签和 Windows 管理窗口提示均已实现。基础远程开关机、更新保留配对及倒计时已登记 v1.1.0 正式版本映射，不再标为待实现。

既有自动化测试和界面检查已有通过记录；真实安装后的 IPC 与跨版本联合验收记录尚未补齐。详细规则见 [版本信息与兼容提示](design/version-compatibility-hints.md)。本次仅整理文档，没有重新运行这些测试。
