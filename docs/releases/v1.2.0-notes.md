# Wollet v1.2.0 发布说明

管理页面显示客户端连接 IP、当前在线时长和 Windows 系统运行时长；Windows 客户端整体迁移至 WPF，保留安装、绑定、更新、修复、卸载和同步关机倒计时功能。

## 设备状态

- 连接 IP 来自服务端看到的 WebSocket 对端；经过 NAT 或反向代理时可能是出口或代理地址。
- 当前在线从本次客户端连接建立开始计时，页面刷新不重置，客户端重连后重新计时。
- 系统运行从 Windows 内核启动开始计时，包含睡眠和休眠；快速启动可能保留时长，完整重启后归零。
- 离线时隐藏当前连接和运行数据；数据过期或状态连接中断时暂停对应计时，恢复后重新校准。
- 修复页面加载时短暂显示旧在线状态的问题。

## Windows 客户端

- 安装／管理窗口和倒计时窗口使用 WPF，支持窗口缩放、键盘操作和系统颜色资源。
- 更新保留现有配对，窗口区分更新、同版修复和降级拦截。
- 客户端产品版本不再自动附加提交哈希。

## 升级与兼容

建议先更新服务端，再运行新版客户端并选择“更新”；无需先卸载或重新绑定。客户端更新本身不依赖服务端先升级。

新服务端配合旧客户端仍可显示连接 IP 和当前在线，系统运行时长显示未知；旧服务端配合新客户端保持基础控制可用。完整状态功能需要两端都支持 `device-status.v1`。

Windows x64 客户端提供两个发行文件：

- `wollet-client-win-x64-runtime.exe`：包含 .NET 10 Runtime，可直接运行。
- `wollet-client-win-x64-framework-dependent.exe`：文件较小，需要 x64 .NET 10 Desktop Runtime。

## 使用边界

- 桌面倒计时仅支持活动控制台会话，不支持 RDP；提示不可见时，已接受的后台计划仍会执行。
- 本版不提供远程休眠、动态调整倒计时时长或自动下载更新。
- WPF 迁移的实测记录对应 Windows 11；Windows 10 和完整显示器矩阵的验证覆盖见 [WPF 迁移记录](../design/wpf-migration.md)。
