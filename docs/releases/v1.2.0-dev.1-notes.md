# Wollet v1.2.0-dev.1 测试发布说明

> 历史发布说明：以下测试范围与验证边界对应 dev.1，后续版本的功能说明见 [v1.2.0 发布说明](v1.2.0-notes.md)。

`v1.2.0-dev.1` 是 v1.2.0 的首个公开测试版，不是正式发布。

本版在管理页面显示客户端连接 IP、当前在线时长和 Windows 系统运行时长，并处理重连、离线、过期和 SSE 恢复。Windows 客户端已从 WinForms 迁移到 WPF，保留原有安装、绑定、更新、修复、卸载、版本兼容提示和同步关机倒计时功能。

如需完整测试新增状态，请先部署 `ghcr.io/fishy-stick/wollet:v1.2.0-dev.1`，再更新 Windows 客户端。客户端从旧版更新时会保留现有配对；更新后服务端仍为旧版时出现“版本不一致／功能受限”提示属于预期兼容行为。

Windows 附件提供两个版本：

- `wollet-client-win-x64-runtime.exe`：推荐，已经包含 .NET 10 Runtime。
- `wollet-client-win-x64-framework-dependent.exe`：体积较小，需要预先安装 x64 .NET 10 Desktop Runtime。

请重点反馈 Windows 10／11 安装升级、休眠和快速启动后的行为、真实关机倒计时、不同 DPI 显示器之间移动、辅助功能，以及双网卡、IPv4／IPv6、DNS／TLS 网络环境中的连接 IP 显示。
