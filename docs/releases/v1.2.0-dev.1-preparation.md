## 本次测试范围

- 管理页面增加连接 IP、当前在线时长和 Windows 系统运行时长，处理重连、离线、过期和 SSE 恢复。
- Windows 客户端整体迁移至 WPF，保留安装、绑定、更新、修复、卸载、兼容提示、本地 IPC 与倒计时行为。
- 更新保留现有配对；首次安装仍需填写服务端地址和 Token。
- 新服务端与旧客户端、旧服务端与新客户端保持基础控制可用；完整的状态字段需要新服务端和新客户端同时运行。

## 面向测试者的已知边界

- Windows 11 已完成实际升级、服务恢复、配对保留和管理窗口检查；Windows 10 尚未实机验证。
- 真实关机、睡眠／休眠／快速启动、混合 DPI 跨屏、系统高对比度和复杂局域网仍需要测试反馈。
- 服务端仍为旧版时，客户端显示“版本不一致／功能受限”是预期兼容提示，不表示更新失败。
- 这是测试版，不能作为正式生产发布依据。

## 计划附件与部署顺序

- `wollet-client-win-x64-runtime.exe`：推荐，包含 .NET 10 Runtime。
- `wollet-client-win-x64-framework-dependent.exe`：较小，要求安装 x64 .NET 10 Desktop Runtime。
- 服务端先部署 `ghcr.io/fishy-stick/wollet:v1.2.0-dev.1`，再更新 Windows 客户端，可完整验证本版新增状态。客户端更新本身不依赖服务端先升级。
